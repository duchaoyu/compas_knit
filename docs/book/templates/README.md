# Templates

Copy one of these to start a new page, then add it to [SUMMARY.md](../SUMMARY.md) so it appears in the book.
Pages not listed in `SUMMARY.md`, like these, are not shown.

* [api-page.md](api-page.md) — one module
* [tutorial.md](tutorial.md) — one task, step by step
* [documentation-page.md](documentation-page.md) — one concept or step of the method

Images go in `.gitbook/assets/` and are linked relative to the page, e.g. `![](../.gitbook/assets/name.png)`.
